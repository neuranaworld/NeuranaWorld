⚙️ 3. MANUEL BAŞLATMA (Alternatif)
═══════════════════════════════════════════════════════════

Eğer BASLAT.bat çalışmazsa:

1. Windows Tuşu + R
2. "cmd" yaz, Enter
3. Sırayla şu komutları yaz:

   cd Desktop\FarmDominion
   python -m http.server 8000

4. Chrome'u aç
5. Adres çubuğuna yaz: localhost:8000
6. Enter!

═══════════════════════════════════════════════════════════
❌ SORUN GİDERME
═══════════════════════════════════════════════════════════

Problem: "Python bulunamadı"
Çözüm: 
1. python.org/downloads adresinden Python indir
2. Kurarken "Add Python to PATH" işaretle
3. Bilgisayarı yeniden başlat

Problem: "Port kullanımda"
Çözüm:
- BASLAT.bat otomatik 8080 portu dener
- Manuel: python -m http.server 8080

Problem: "Çok yavaş"
Çözüm:
- ESC → Grafik → Düşük
- Gölgeleri kapat (G tuşu)
