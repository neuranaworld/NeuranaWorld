## 💡 İLK OYNAYIŞTA YAPMALISIN

### Adım 1: Ayarları Düzenle
```
1. ESC tuşuna bas
2. "Grafik Ayarları" bölümüne git
3. Kaliteyi PC'ne göre seç
4. UI elemanlarını kişiselleştir
```

### Adım 2: Kontrolleri Öğren
```
1. Ayarlar menüsünde "Kontroller" bölümünü oku
2. WASD ile hareket et
3. Shift ile koş
4. Space ile zıpla
```

### Adım 3: İlk Görevi Tamamla
```
1. Sağ üstteki görev paneline bak
2. "Çiftliğe Hoşgeldin" görevi aktif
3. 5 binayı ziyaret et
4. Ödülünü topla! 🏆
```
